# Zenit — site institucional

Site one page da Zenit (estrutura digital e acompanhamento): SEO local, tráfego pago, sites, one page, e-commerce e automações.

Feito em HTML, CSS e JavaScript puros: não precisa de build. Basta abrir o `index.html` ou publicar a pasta em qualquer hospedagem estática (Vercel, Netlify, GitHub Pages).

## Antes de publicar
- `assets/main.js`: troque `WHATSAPP` pelo número real (ex.: `5511999999999`).
- Identidade visual: segue o design system ZENIT (tokens no topo de `assets/style.css`, logos oficiais em `assets/brand/`).
- `index.html`: ajuste o e-mail, o Instagram e os textos do FAQ.
